# TV YoshiCat

Canais de TV e rádios abertos e legais de todo o mundo, numa app que se instala no ambiente de trabalho.

- Lista de canais: [iptv-org/iptv](https://github.com/iptv-org/iptv) (links públicos de emissões abertas)
- Rádios: [Radio Browser](https://www.radio-browser.info/) (base de dados aberta)
- Abrir: https://quinta-yoshicat.github.io/tv-yoshicat/
